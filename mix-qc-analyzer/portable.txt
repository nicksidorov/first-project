QC MIX ANALYZER — WINDOWS x64, VERSION 1.0

Распакуйте ZIP и запустите MIX_QC.exe. Установка Python и Excel не нужна.
Программа создаёт XLSX-файлы библиотекой openpyxl; для просмотра отчёта
подойдёт Excel или другая программа с поддержкой XLSX.

1. Reference spectrum — выберите шаблонный .PHD.
2. Folder — выберите папку со спектрами .PHD/.phd (без вложенных папок).
3. Save spectra to folder — сохранять интерактивные HTML-графики.
4. Use Poisson MLE (iterative reweighting) — итеративное перевзвешивание
   IRLS: на каждой итерации sigma = sqrt(текущего предсказания модели).
   Если галочка снята, используются фиксированные веса по отсчётам.
5. Run calculation — выберите, куда сохранить Excel-отчёт.

Графики появляются рядом с Excel в папке <имя отчёта>_plots.
HTML открывается обычным браузером и работает без интернета.
Файлы спектров не изменяются. Программа не передаёт данные в сеть.
При закрытии окна во время расчёта нужно дождаться завершения обработки.

Изначальные модель и численные параметры сохранены:
- матрица 256×256, отсечение y<40 и x+y<190;
- проекция по оси 0, LOWESS и CubicSpline;
- бета-подгонка A/k · шаблон(x/k), каналы 9–220;
- для IRLS до 50 итераций, порог относительного изменения 1e-6;
- гамма-пик: гауссиана и линейный фон, каналы 209–251.

В Excel столбец «Сходимость IRLS» показывает достижение критерия сходимости
или лимит итераций. Лимит не считается подтверждением сходимости.
Ошибки подгонки помещаются на отдельный лист, ошибка гамма-пика не скрывает
результат бета-подгонки. Валидность методики QC проверяется отдельно.

Сборка включает научные библиотеки и поэтому больше простого просмотрщика.
При запуске EXE распаковывает компоненты во временную папку; выходные отчёты
сохраняются в выбранное вами постоянное место.
