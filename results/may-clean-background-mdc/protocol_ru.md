# Номинальный MDC на чистом детекторном фоне

План начальной серии зафиксирован до просмотра её результатов.

## Модель

Используются полные модели V86 21×17 двух прежних майских комплектов (SAMPLE 22 и 26 мая). Времена, сбор, задержки, объёмы и калибровки сохранены; ROI и эффективности фиксированные, детектор 221, радон legacy. Исходные файлы и ядро проверены по SHA256.

Генерирующая истина: a_V=0 и gamma=0 для всех пяти компонентов, включая радон; zeta равна исходным наблюдаемым отсчётам прежнего DETBK по ROI [1,2,3,5,6,7,8]: [522,854,494,66,64,89,97]. Никакие результаты совместной подгонки реальных SAMPLE/GASBK не используются для задания фонового среднего. Параметр zeta означает ожидаемые отсчёты за длительность DETBK; скорости равны zeta/T_D.

При сигнале меняется только одна свежая активность a_V[i]. Вклад цепочки распада сохраняется в соответствующем полном физическом столбце S_V. Все 21 наблюдение SAMPLE/GASBK/DETBK разыгрываются независимо по Пуассону. Во время обработки все 17 параметров остаются свободными для оценивания, включая память, остальные изотопы, радон и детекторный фон. Систематические ошибки не моделируются.

## Два значения предела

1. Формульный номинальный MDC: итерационный расчёт приложения на точно заданной фоновой смеси с полной информационной матрицей. Значение одно для этой смеси и не зависит от выбора МНК/ММП.
2. Эмпирический Ld95: активность, обеспечивающая 95% обнаружения действующей процедурой Lc, определяемая по мощности повторной полной обработки. Для МНК и ММП он может различаться.

В каждой реализации свободная оценка сравнивается с Lc из соответствующей неотрицательной подгонки с удалением целевого свежего вклада. Для МНК веса 1/max(x*,1) обновляются. В расчёте мощности mode=fixed только пропускает неиспользуемую итерацию MDC; Lc точно совпадает с mode=iterative. Критические коэффициенты не калибруются. Вальд и профильный критерий не используются.

## План и точность

Нулевая серия: по 5000 реализаций для каждого комплекта, общие наблюдения для четырёх проверок изотопов. Поисковая серия: по 500 реализаций для каждой пары комплект/изотоп при A=0.8,1.0,1.2,1.4 от формульного MDC. Всего в начальной серии 26000 новых векторов.

После поиска фиксируется отдельная подтверждающая сетка из трёх точек для каждой пары комплект/изотоп, по 3000 новых независимых реализаций на точку. Сетка общая для МНК и ММП. Если она не охватывает 95% хотя бы для одного метода, добавляются заранее объявленные новые независимые точки; старые результаты не удаляются. Технические серии по 40 реализаций для 10 сценариев исключаются.

Seed=[2026102201, индекс комплекта, индекс изотопа (0 для нулевой серии), round(10000*множитель MDC), код этапа, номер блока]. Все точки/блоки имеют разные seed; оба метода анализируют одни и те же наблюдения. Пропуски сохраняются, не заменяются новыми векторами.

Ld95 оценивается локальной линейной интерполяцией подтверждающих точек. Поисковые точки не входят в формальную оценку. Неопределённость показывается посредством биномиальных интервалов мощности и консервативных сеточных границ при предположении монотонности истинной мощности. Интерполяция приближённая. Выводы условны относительно выбранного фонового среднего и фиксированных калибровок.

Для возможных расширений заранее ограничено число дополнительных точек: не более четырёх на кривую. С учётом трёх исходных подтверждающих точек и нуля максимум восемь точек. Сеточные границы используют фиксированный уровень каждой точки 1−0.05/8=0.99375; этот бюджет не зависит от числа фактически потребовавшихся расширений. Bootstrap условен относительно итоговой сетки. Правило записано до просмотра подтверждающих результатов.

## Уточнение после подтверждающей серии

Для Xe133m комплекта 22 мая нижняя подтверждающая точка дала мощность 0.948/0.949. Хотя точечное пересечение 0.95 уже было найдено, значительная доля bootstrap-кривых уходила за нижнюю границу сетки. После просмотра этих результатов решено добавить независимую нижнюю точку A=1.0 формульного MDC (3000 новых реализаций). Это уточнение ради полноты интервала, а не первоначально запланированная точка. Причины и выбранные активности записываются в extension_selection.json до генерации новых данных; прежние точки сохраняются. Уровень одновременных сеточных интервалов остаётся прежним.
