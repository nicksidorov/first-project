# Математика XeMat и соответствие статье

Основная спецификация — предоставленная автором статья `XeMat_RU_MASTER_BAYES_V59.tex`, разделы совместной
модели, МНК/ММП, неотрицательного оценивания, активностей и MDC. Имена уравнений
ниже — `\label` из статьи, устойчивые к изменению нумерации формул.

| Величина или формула статьи | Программа |
| --- | --- |
| `x=[c;d]`, исходные SAMPLE/GASBK | `JointModel.x` |
| `b_det=[κ_s b;κ_g b]`, фиксированный DETBK | `JointModel.b` |
| `R_F=[[R_c,R_g1 F],[0,R_g2]]`, `eq:joint_model` | `build_joint_matrix`, `JointModel.M` в `beta_gamma` |
| `mu=M theta+b`, `eq:expected_counts` | `FitResult.mu` |
| `theta=[beta;gamma]` | `FitResult.theta` при `coordinates='beta_gamma'` |
| `T_c=G_s G_p Γ H/V0`, `eq:activity_parameter_transform` | `JointModel.T_c`, `compute_activities` |
| `z=a_c^(gamma)=[a_c;gamma]` | `FitResult.physical_parameters` |
| `S_c=R_F diag(T_c^-1,I)`, `eq:concentration_response_matrix` | `JointModel.physical_matrix` |
| `W=Omega_hat^-1`, `eq:wls_weights` | `fit(..., weights=...)`, схема по исходным `x` по умолчанию |

## Координаты и ограничения

Входные `coordinates` задаются явно: `beta_gamma` означает `M=R_F`,
`a_c_gamma` означает `M=S_c`. `theta` всегда возвращается во входных
координатах; `physical_parameters` всегда в `[a_c;gamma]`, когда преобразование
известно. Свободные методы допускают отрицательные параметры. NNLS и
неотрицательный ММП решают задачу непосредственно в `[a_c;gamma]>=0`.
При цепочках `beta>=0` не гарантирует `a_c>=0`.

Первая компонента статьи — радоновый мешающий вклад. Его активность в
детекторе имеет смысл, но первая координата `a_c` является вспомогательным
перенормированным параметром, а не атмосферной объёмной активностью радона.
Для стандартного порядка `[Rn222,Xe135,Xe133,Xe131m,Xe133m]` используйте
`mdc_component_indices=[1,2,3,4]`. Полный радоновый столбец остаётся в модели.

## Один квадратичный критерий

Оба квадратичных метода минимизируют
`(x-b-M theta)^T W (x-b-M theta)` в своих координатах. Веса по статье:
`w_i=1/x_i` при `x_i>0`, `w_i=1` при `x_i=0`. Это оценка пуассоновской
ковариации по наблюдению. Единицей заменяется только нулевая дисперсия;
исходные отсчёты не изменяются. Использование `1/(x+1)` для всех ROI изменило
бы критерий и здесь не применяется.

Можно передать `weights` (положительный вектор или полную SPD-матрицу W)
либо `observation_covariance` (полную SPD-матрицу Ω). Эти параметры взаимоисключающие.
При внешних весах статистическая ковариация предполагает `Ω=W^-1`.
Фон фиксирован по статье; его неопределённость автоматически не добавляется.
Если внешняя Ω учитывает неопределённость общего DETBK, задайте также
межблочные корреляции SAMPLE/GASBK.

Решение использует отбеливание, масштабирование столбцов и SVD/устойчивый
ограниченный решатель, без явного обращения нормальных уравнений и без ridge.
Недостаточный ранг означает неидентифицируемость: конечные ошибки отдельных
параметров в этом случае не выдаются. Ковариация не домножается на reduced χ².

## Пуассоновские методы

Используются исходные целочисленные `x`, включая нули; `b` входит в `mu`.
Критерий `sum(mu-x*log(mu))` (без постоянного `log(x!)`) либо эквивалентный
девианс. При `x=0` вклад `x log(mu)` равен нулю. По прямому требованию
пользователя допускается `mu=0` при `x=0`; при `x>0` нужно `mu>0`.
Это расширяет строго положительную область, записанную в статье.
Недопустимые ожидания не подменяются положительными числами.
Ограничения на `mu` сохраняются и в свободном методе; искусственных границ
на величину параметров нет.

Свободный решатель использует SVD-базис, ограниченный — положительное
диагональное масштабирование, сохраняющее область физических параметров.
Для обычной неотрицательной S_c используется L-BFGS-B; для общей знаковой
матрицы сохраняются явные линейные ограничения. Сходимость подтверждается
проверкой допустимости и условий ККТ. Остаток округления на активной границе
может устраняться малой допустимой поправкой **параметров**, с повторным
вычислением mu и диагностическим сообщением; сами mu не обрезаются.

Ковариация свободного ММП вычисляется по ожидаемой информации Фишера.
При нулевом модельном ожидании обычная формула не определена.
Ковариации ограниченных оценок не выдаются как свободные ковариации:
в частности, активная граница имеет другое распределение оценки.

## Активности и MDC

Передаются готовые H, Γ, G_p, G_s, V0 либо готовая T_c. Вся цепочка и
распространение ковариаций выполняются явными матричными операциями.
Единицы H и T_c должны соответствовать статье: Бк и Бк/м³ соответственно.
Пересчёта мБк в ядре нет; нельзя применять поправки повторно к уже
преобразованной физической модели.

Для MDC одна свободная подгонка задаёт оценку для решения об обнаружении,
одна полная неотрицательная — физический нулевой спектр. Из него вычитается
только свежий вклад проверяемого нуклида. Память того же нуклида сохраняется.
Столбцы из S_c не удаляются, nuisance не подгоняются заново на итерациях.
`K_i(L)=[S_c^T diag(1/(mu0+L*s_i)) S_c]^-1`,
`LC=z_(1-alpha)*sqrt(K_i(0)[i,i])`,
`MDC=LC+z_(1-beta_II)*sqrt(K_i(MDC)[i,i])`.
Обнаружение: **свободная оценка `a_c[i]>LC`**, а не сравнение с MDC.
Нулевой спектр должен быть строго положительным, матрица полного ранга.
Недоступность или несходимость расчёта сообщается явно, без `abs` или
подмены MDC запасным числом.

MDC в этой версии использует именно модельную пуассоновскую ковариацию
статьи при фиксированном фоне. Переданная для МНК внешняя ковариация
не подменяет `K_i(L)` автоматически; её дополнительные источники ошибок
потребуют отдельного расширения модели MDC.

## Формат NPZ

Массивы загружаются с `allow_pickle=False`. При передаче `R_c,R_g1,R_g2,F`
координаты должны быть `beta_gamma`; для `a_c_gamma` передайте готовую `M=S_c`.

| Поле | Форма и назначение |
| --- | --- |
| `M` | `(m,p)` готовая матрица; альтернатива `R_c,R_g1,R_g2,F` |
| `x`, `b` | `(m,)` исходные целые отсчёты и неотрицательный фон; необязательны при трёх IMS-файлах |
| `n_sample_parameters` | целочисленный скаляр, число первых параметров пробы |
| `coordinates` | Unicode-скаляр `beta_gamma` или `a_c_gamma` |
| `T_c` | `(n,n)` невырожденный перевод beta в a_c |
| `H`, `Gamma`, `G_p`, `G_s`, `V0` | подготовленные преобразования активностей |
| `weights` или `observation_covariance` | внешние веса или ковариация для квадратичных методов |
| `isotope_names`, `parameter_names` | строки для отчёта |
| `sample_roi_numbers`, `gasbk_roi_numbers` | порядок ROI для файлов; `roi_numbers` — общий порядок |
| `mdc_component_indices` | явно выбранные индексы ксенона с нуля, только из блока пробы |
| `alpha`, `beta_ii` | вероятности ошибок, по умолчанию 0.05 |
| `mdc_mode` | `iterative` по статье; `fixed` — отдельно помеченное приближение постоянной дисперсии |
| `delta_I`, `delta_V0` | дополнительные относительные стандартные неопределённости |

Числа, единицы, порядок компонент и ROI являются частью физической
спецификации файла. Пример содержит учебные матрицы и не заменяет калибровку.
ROI должны быть непересекающимися для независимого пуассоновского критерия
и модели MDC статьи. Адаптер трёх файлов проверяет это после калибровки,
округления и ограничения каналов ровно как в сохранённом парсере; общий
конечный канал также означает пересечение. Полные перекрывающиеся ROI
старой таблицы (например, ROI 4 вместе с 5–8) выбирать совместно нельзя.
В NPZ с готовыми `x,b` непересечение является обязанностью составителя модели.
