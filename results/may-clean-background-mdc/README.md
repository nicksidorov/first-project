# Номинальный MDC на чистом детекторном фоне

Времена, объёмы и калибровки — из двух майских комплектов XeMat. В генерирующей смеси нет пробы, памяти и радона; каждый изотоп Xe вводится отдельно. При обработке сохраняются все 17 параметров полной модели, а детекторный фон оценивается заново.

## Что сравнивается

Формульный MDC вычисляется итерационно при заданной фоновой смеси по полной информации Фишера. Ld95 по мощности находится из повторной полной обработки пуассоновских реализаций; в каждой реализации Lc пересчитывается по нашей процедуре с удалением целевого свежего вклада из неотрицательной подгонки. Фактические ложные обнаружения проверяются отдельно. Критические коэффициенты не калибруются.

## Данные и воспроизведение

`manifest.json` содержит полные матрицы, исходные метаданные, нулевую генерирующую смесь, формульные пороги, версии и SHA256 неизменённого математического ядра. Фон zeta задан по прежнему DETBK: [522,854,494,66,64,89,97] отсчётов в ROI [1,2,3,5,6,7,8] за 259200 с. Исходные SAMPLE/GASBK не использованы для оценки генерирующего фонового среднего.

`trials_compact.npz` сохраняет все 21 исходный отсчёт каждой реализации, четыре целевые свободные/неотрицательные активности и рассчитанные Lc/решения. Единицы NPZ — Бк/м³; таблицы и графики — мБк/м³. Индекс блоков, seed и маски рассчитывавшихся изотопов находятся в `trials_compact_index.json`. Для ненулевой пробы проверяется только вводимый изотоп; NaN/-1 остальных столбцов означает отсутствие этой проверки.

Графики и отчёт можно восстановить без повторных подгонок командой `python report.py`: при отсутствии папки `points` программа читает сохранённый компактный NPZ.

Весь эксперимент использует ядро коммита `3faf592c33f1dfd89ad3fcfee6f41d2893a1748a`. Для повторения подгонок в окружении этого проекта задайте `XEMAT_REPO` равным пути к папке XeMat. С готовым manifest можно заново выполнить сохранённые планы командой `python study.py run --plan initial_plan.json`, затем `confirmation_plan.json` и `extension_plan.json`, если он есть. `verify.py` проверяет полные повторные расчёты из `points`, `package.py` создаёт архив. `study.py prepare` нужен только в первоначальной среде подготовки и для готового архива не требуется.

Пакеты: NumPy, SciPy, Matplotlib. В приложении ничего не менялось. Результаты условны относительно принятого фонового уровня и фиксированных калибровок.
