# Номинальный MDC после калибровки Lc на чистом фоне

## Цель и модель

Сопоставить МНК и ММП при целевой ложноположительной частоте 5% и определить активность одного изотопа, обеспечивающую 95% обнаружений. Используется полная модель V86, 21 наблюдение и 17 оцениваемых параметров, в координатах [a_V; gamma; zeta]. Интерфейс, парсинг и математическое ядро приложения не меняются.

Условия — прежние комплекты 22 и 26 мая: фиксированные ROI и эффективности, матрицы детектора 221, времена и пересчёт объёма сохранены. Генерирующий фон zeta=[522,854,494,66,64,89,97] задан по исходному DETBK за 259200 с. В нулевой смеси все активности пробы, памяти и радона равны нулю. SAMPLE, GASBK и DETBK независимо разыгрываются по Пуассону; при анализе все параметры, включая детекторный фон, оцениваются заново. Систематические ошибки не моделируются.

## Калибровка и независимая проверка

На каждый комплект заранее назначены 20000 новых нулевых реализаций для калибровки и 10000 других новых реализаций для проверки. Старые нулевые серии не используются для настройки или независимой проверки. Оба метода и четыре изотопа используют одни и те же наблюдения внутри каждой серии.

Стандартный Lc в каждой реализации вычисляется прежней процедурой: неотрицательная вспомогательная подгонка, удаление только целевого свежего вклада из ожидаемого спектра, полная ковариация. Решение использует свободную оценку активности. Определяется R=оценка активности/Lc. Отсчёты наблюдений не вычитаются.

Для каждой пары метод/изотоп и каждого комплекта коэффициент c равен k-й порядковой статистике R, где k=ceil((n+1)*0.95). При n=20000 это 19001-я величина по возрастанию. Правило обнаружения: R>c, то есть оценка активности>c*Lc. Равенство не считается обнаружением, искусственный шум для устранения совпадений не добавляется. При непрерывном распределении усреднённый по случайным калибровочным сериям уровень равен 1000/20001, почти 5%; для конкретного полученного c фактический уровень остаётся неизвестным и проверяется отдельно. При совпадениях правило может быть консервативнее.

Все 20000 калибровочных значений должны быть доступными: ошибочные подгонки не исключаются молча. Коэффициенты и их исходные хеши сохраняются до чтения независимой проверочной серии. По результатам проверки коэффициенты не перенастраиваются. Показываются фактические частоты и точные биномиальные 95% интервалы, а не утверждение о математически точных 5%.

## Мощность и Ld95

После фиксации c повторно используются 75000 сохранённых сигнальных реализаций предыдущего исследования: только этапы confirm и extend. Они независимы от новой калибровки. Прежние поисковые screen-серии и нулевые серии в формальные кривые мощности не входят. Для каждой исходной реализации сохраняются обе оценки и стандартный Lc; новое решение получается сравнением R с фиксированным c. Другие изотопы и память при генерации нулевые, вводится только один свежий изотоп. Цепочечные вклады сохраняются физической матрицей.

Стандартный и откалиброванный Ld95 оцениваются на одной общей сетке активностей линейной интерполяцией около мощности 0.95. Если пересечение или приближённый интервал не помещается на сетке, разрешено не более четырёх новых независимых точек по 3000 реализаций на кривую. Их активность и причина фиксируются до генерации, все прежние данные сохраняются. Выбор старой сетки по прежним поисковым результатам явно учитывается как ограничение интерполяционного анализа.

## Неопределённость

Интервал коэффициента c строится непараметрически через биномиальные ранги порядковых статистик. Условный bootstrap-интервал Ld95 фиксирует найденный c и учитывает только случайность сигнальных реализаций. Дополнительный bootstrap с повторной калибровкой учитывает неопределённость оценки идеального порога — 95-го процентиля нулевого распределения — и соответствующего Ld95.

В каждой из 2000 bootstrap-реализаций калибровочные строки выбираются совместно для обоих методов и четырёх изотопов. Один полученный c_b применяется ко всем активностям данной кривой. Сигнальные решения МНК/ММП пересэмплируются совместно через мультиномиальное распределение четырёх пар исходов; это сохраняет корреляцию методов. Выход пересечения за сетку отражается явно; такие реализации не удаляются ради сужения интервала. Bootstrap условен относительно выбранной сетки и не включает ошибку формы кривой между узлами, неопределённость калибровочных матриц или фонового среднего.

Дополнительные консервативные сеточные границы используют предположение монотонности истинной мощности. Максимум точек с нулём — девять: до четырёх старых, до четырёх новых, одна нулевая. Для фиксированного c уровень каждого биномиального интервала равен 1−0.05/9. Для границ с неопределённым c используется его 97.5% интервал и одновременные биномиальные интервалы уровня 1−0.025/(2*9) на обоих концах интервала c. Бюджеты фиксированы до чтения новых результатов.
