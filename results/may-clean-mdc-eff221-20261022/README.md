## Что рассчитано

1. Формульные Lc и номинальный MDC при заданном чистом детекторном фоне.
2. Частота ложных обнаружений исходной процедуры Lc.
3. Отдельная калибровка множителя `c` в правиле `A_hat > c × Lc` к целевому уровню 5% и независимая проверка этого уровня.
4. Ld95 — активность одного введённого изотопа, при которой исходная или откалиброванная процедура даёт около 95% обнаружений.

В каждом повторе заново генерируются все **21 отсчёт SAMPLE/GASBK/DETBK** и оцениваются все **17 параметров**. При генерации свежая проба, память и радон нулевые; для мощности вводится только один свежий изотоп. Детекторный фон при обработке оценивается заново. Исходное среднее DETBK задаётся прежними наблюдениями. Фиксированные ROI, матрицы R, времена и объёмы сохранены. Систематические ошибки не моделируются. Вальд и профильные тесты в этом исследовании не рассчитываются.

Новый Ld95 по Монте-Карло является **численной оценкой**, а не математически точным пределом. Он получен интерполяцией кривой мощности около 95%. Условный bootstrap-интервал оценивает Ld95 для найденного фиксированного множителя `c_hat`; интервал с неопределённостью калибровки оценивает Ld95 для идеального множителя `c0`, равного 95-му квантилю нулевой статистики. Интервалы не учитывают ошибку формы кривой между узлами, систематику и неопределённость выбранного фонового среднего.

Целевые 5% относятся к проверке **одного изотопа**, а не к вероятности хотя бы одного ложного обнаружения среди четырёх. По результатам независимой проверки множители повторно не настраиваются. Поправка относится к этим чистым фоновым условиям; её перенос на произвольные реальные смеси отдельно не проверялся.

## Данные и воспроизведение

`manifest.json` содержит полные новые матрицы, нулевую генерирующую смесь, времена, объёмы, калибровки, seed и контрольные суммы. Физические матрицы перестроены с новыми эффективностями, включая цепочечный вклад Xe133m → Xe133. Старые оценки Монте-Карло не пересчитывались простым масштабированием и не включались в новые серии.

`points/*.npz` сохраняют все исходные сгенерированные векторы и полные свободные/неотрицательные оценки параметров, Lc и решения. Соответствующие JSON содержат условия, seed и зарегистрированные ошибки. Старые документы `prior_formula_manifest.json`, `prior_formula_summary.json`, `prior_calibrated_manifest.json` и `prior_calibrated_summary.json` скопированы без изменений и используются только для исторического сравнения. Старые и новые Монте-Карло серии независимы.

В репозитории исходные блоки `points/` доступны **внутри полного архива**, без отдельной дублирующей папки. Для запуска `analyze.py` или `verify.py` сначала распакуйте полный архив в отдельную папку и выполняйте команды из неё. Корневой `sha256.json` содержит контрольные суммы полного набора файлов, включая эти блоки.

Единицы активностей в сырых массивах и моделях — **Бк/м³**; в итоговых таблицах и графиках — **мБк/м³**. Вероятности в JSON записаны долями, не процентами. Контрольные суммы содержимого полного архива перечислены в `sha256.json`, небольшого архива отчёта — в `sha256_report.json`.

Для восстановления отчёта из готовых результатов выполните:

```bash
python report.py
```

Требуются NumPy и Matplotlib. Повторные подгонки для построения отчёта не нужны. Команда `python analyze.py` заново вычисляет итоговую сводку из сохранённых результатов; дополнительно нужна SciPy. Все необходимые серии находятся в архиве, соседние каталоги прежних экспериментов не требуются.

Независимая проверка выполняется командой `python verify.py`; доступные параметры смотрите через `python verify.py --help`. Для повторения подгонок нужна версия XeMat, указанная в `manifest.json` (`69ff5a62ccaaddeb6372f7f003109ce5ff6cf333`). Путь к проекту задаётся переменной окружения `XEMAT_REPO`. При проверке распакованного архива результат аудита следует записывать вне него, чтобы сохранить контрольные суммы опубликованных файлов.

Полный расчёт повторяют в **отдельной рабочей копии** со скриптами, входным `manifest.json` и планами, без уже рассчитанных серий и файлов замороженной калибровки:

```bash
python study.py --plan calibration_plan.json
python calibration.py --freeze
python study.py --plan validation_plan.json
python study.py --plan signal_plan.json
```

После завершения всех серий выполняют `python analyze.py --preview`, проверяют покрытие сигнальной сеткой и, если требуется, запускают отдельно сохранённые планы расширения. Затем выполняют `python analyze.py`, `python verify.py` и `python report.py`. Скрипт `package.py` создаёт оба ZIP только после успешной независимой проверки, завершения сетки и проверки неизменности замороженных файлов. Для каждого архива проверяются CRC и контрольные суммы всех файлов; размер и SHA256 архива выводятся в консоль. Калибровка использует только свою нулевую серию и фиксируется до независимой проверки.

Для повторной подготовки физических матриц из исходных PHD предназначен `prepare.py`. Архивные абсолютные пути к исходным спектрам служат указателями происхождения; если эти файлы перенесены, пути нужно явно заменить в отдельной рабочей копии. Готовый `manifest.json` достаточен для повторения самого Монте-Карло.
