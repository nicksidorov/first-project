# Gamma Spectrum Viewer

Небольшая программа на Python для просмотра бинарных гамма-спектров.
График Plotly встроен в окно PyQt5 и работает без интернета.

## Установка и запуск

Нужен Python 3.10 или новее и графическая сессия. Для первого запуска
рекомендуется Python 3.11 или 3.12, для которых доступны готовые пакеты Qt.

Скачайте [архив только этой программы](https://github.com/nicksidorov/first-project/raw/refs/heads/main/gamma-spectrum-viewer/gamma-spectrum-viewer.zip),
распакуйте его и откройте терминал в папке `gamma-spectrum-viewer`.

Либо клонируйте репозиторий и перейдите в папку программы:

```bash
git clone https://github.com/nicksidorov/first-project.git
cd first-project/gamma-spectrum-viewer
```

В папке программы создайте окружение:

```bash
python -m venv .venv
```

Активируйте окружение:

Windows (PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
```

Linux / macOS:

```bash
source .venv/bin/activate
```

Установите зависимости, создайте искусственный пример и откройте его:

```bash
python -m pip install -r requirements.txt
python examples/make_demo.py
python spectrum_viewer.py examples/demo.bin
```

Чтобы выбрать файл через диалог:

```bash
python spectrum_viewer.py
```

Либо установите проект как пакет:

```bash
python -m pip install .
python examples/make_demo.py
gamma-spectrum-viewer examples/demo.bin
```

В Linux при отсутствии команды `python` используйте `python3`.
Qt WebEngine требует системные библиотеки графической среды; запускайте
программу от обычного пользователя. Без дисплея или рабочего OpenGL-контекста
окно может не открыться.

## Возможности

- Выбор бинарного файла через диалог или аргумент командной строки.
- Масштабирование выделением мышью, перемещение и значения под курсором.
- Двойной щелчок для сброса масштаба.
- Линейная и логарифмическая шкала по Y.
- Число каналов, сумма импульсов и положение максимума.
- Экспорт автономного HTML, CSV с разделителем `;` и PNG через панель Plotly.

HTML содержит библиотеку Plotly, поэтому для просмотра не требуется интернет.
На логарифмической шкале нулевые значения не отображаются; исходные значения
при этом не меняются.

## Формат бинарника

Программа читает следующий формат:

| Параметр | Значение |
| --- | --- |
| Тип числа | Беззнаковое 32-битное целое (`uint32`) |
| Порядок байтов | Big-endian |
| Размер одного канала | 4 байта |
| Заголовок | Отсутствует |
| Количество каналов | Размер файла / 4 |
| Ось X | Номер канала, начиная с 0 |
| Ось Y | Число импульсов |

Энергетическая калибровка не задана: номера каналов не переводятся в кэВ.
Пустой файл и размер, не кратный четырём, вызывают сообщение об ошибке.
Проверка размера не определяет чужие бинарные форматы или наличие заголовка:
такие файлы не поддерживаются.

## Пример

`python examples/make_demo.py` создаёт `examples/demo.bin`: искусственный спектр
из 4096 каналов с фоном и тремя гауссовыми пиками. Он нужен только для проверки
интерфейса и не представляет реальное измерение. Исходные пользовательские
спектры в репозиторий не входят. Свой бинарный файл выберите кнопкой открытия
или передайте его путь при запуске.

## Структура

```text
spectrum_viewer.py     # окно, чтение данных и график
requirements.txt      # зависимости для запуска из исходников
pyproject.toml        # установка как Python-пакета и команда запуска
examples/make_demo.py # генератор искусственного спектра
tests/test_spectrum.py # проверки чтения и построения графика
```

## Проверки

После установки зависимостей:

```bash
python -m unittest discover -s tests -v
```

Проверяются формат uint32 big-endian, граничные значения, ошибки входных
данных, создание искусственного примера и обе шкалы Plotly. Для этих проверок графическая
сессия не нужна. Проверки не заменяют ручную проверку окна Qt на вашем компьютере.

## Удаление проекта

Все файлы этой программы находятся в папке `gamma-spectrum-viewer`. Чтобы убрать
её из текущей версии репозитория, удалите эту папку и сохраните изменение коммитом.
Предыдущие версии останутся в истории Git.
