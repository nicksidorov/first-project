# Gamma Spectrum Viewer — компактная версия

Оконная программа для просмотра бинарных гамма-спектров. График рисуется
средствами **Tkinter**: только стандартная библиотека Python, без сторонних
зависимостей для запуска. Работает полностью локально и без интернета.

## Переносная версия для Windows

[Скачать GammaSpectrum-Windows-x64.zip](https://github.com/nicksidorov/first-project/raw/refs/heads/main/gamma-spectrum-viewer/portable/GammaSpectrum-Windows-x64.zip)

**Размер архива: 11,2 МБ. Размер EXE: 11,4 МБ.**

1. Распакуйте архив в любую доступную папку или на флешку.
2. Запустите **GammaSpectrum.exe**.
3. Нажмите **«Открыть файл…»** и выберите бинарник. **«Пример»** показывает искусственный спектр.

Целевая система: **Windows 10/11, 64 бита (x64)**. Устанавливать Python или
библиотеки не нужно. EXE также можно скопировать отдельно из архива.
Бинарный файл можно перетащить на значок EXE в Проводнике.

Приложение не устанавливает службы и не сохраняет настройки. При запуске
один EXE распаковывает встроенный Python и Tk во временную папку, которая
удаляется после штатного закрытия. Это переносимая сборка для Windows;
для macOS и Linux нужны свои сборки или запуск из исходников.

## Управление

- Колесо мыши: увеличение/уменьшение вокруг указателя.
- Выделение левой кнопкой: показать выбранный диапазон каналов.
- Перетаскивание правой кнопкой: сдвинуть диапазон.
- Двойной щелчок, **«Сброс масштаба»** или **Ctrl+0**: показать весь спектр.
- **Ctrl+O**: открыть файл. **Escape**: отменить выделение.
- Вертикальный масштаб автоматически выбирается по видимым каналам.
- **«Логарифмическая Y»**: переключение шкалы. Нули скрываются с разрывом
  линии, исходные значения не меняются.
- Под графиком показано точное число импульсов в канале под указателем.
- **CSV**: все исходные значения, разделитель `;`, UTF-8 с BOM.
- **SVG**: текущий вид графика; векторный файл открывается обычным браузером.

На больших спектрах отрисовка сохраняет минимумы и максимумы каждого столбца
экрана, чтобы узкие пики не терялись. Значение под указателем и экспорт CSV
всегда используют исходные каналы. В компактной версии экспорт графика — SVG;
экспорт Plotly HTML и PNG не используется.

## Формат файла

| Параметр | Значение |
| --- | --- |
| Тип числа | Беззнаковое 32-битное целое (`uint32`) |
| Порядок байтов | Big-endian |
| Размер одного канала | 4 байта |
| Заголовок | Отсутствует |
| Количество каналов | Размер файла / 4 |
| Максимальный размер | 4 МиБ, 1 048 576 каналов |
| Ось X | Номер канала, начиная с 0 |
| Ось Y | Число импульсов |

Энергетическая калибровка не задана: номера каналов не переводятся в кэВ.
Пустые, слишком большие файлы и размер, не кратный четырём, отклоняются.
Проверка размера не распознаёт другие бинарные форматы и заголовки.
Пользовательские измерения в репозиторий и дистрибутив не включены.
Демонстрационный спектр искусственный и не представляет реальное измерение.

## Запуск исходников

Нужен Python 3.10+ с Tkinter. В установщике Python для Windows компонент Tcl/Tk
обычно включён по умолчанию. В Debian/Ubuntu для системного Python используется
пакет `python3-tk`.

[Скачать архив исходников](https://github.com/nicksidorov/first-project/raw/refs/heads/main/gamma-spectrum-viewer/gamma-spectrum-viewer.zip)

Распакуйте архив, откройте терминал в `gamma-spectrum-viewer` и выполните:

```bash
python spectrum_viewer.py
```

Либо клонируйте репозиторий:

```bash
git clone https://github.com/nicksidorov/first-project.git
cd first-project/gamma-spectrum-viewer
python spectrum_viewer.py /path/to/spectrum.bin
```

Установка через `pip` для запуска скрипта не нужна.
Если нужна установленная команда запуска: `python -m pip install .`, затем
`gamma-spectrum-viewer`.

Создать отдельный искусственный бинарник:

```bash
python examples/make_demo.py
python spectrum_viewer.py examples/demo.bin
```

## Сборка EXE

На Windows с Python 3.12 x64 запустите в PowerShell:

```powershell
.\build_windows.ps1
```

Скрипт создаёт отдельное `.build-venv`, устанавливает закреплённую версию
PyInstaller, запускает тесты и собирает `dist/GammaSpectrum.exe`.
Сборка идёт в чистом окружении, чтобы сторонние пакеты не увеличивали размер.

В GitHub Actions доступен ручной workflow **Build Gamma Spectrum Portable**.
Он собирает EXE на Windows, запускает его из пути с пробелом и кириллицей,
удаляет Python из `PATH` на время проверки, проверяет окно, чтение спектра,
масштаб, логарифм и экспорт, затем сохраняет переносной ZIP и SHA-256.

## Проверки

```bash
python -m unittest discover -s tests -v
```

Для проверки окна в графической сессии:

```bash
python spectrum_viewer.py --self-test smoke.json
```

Модульные проверки покрывают uint32 big-endian, нули, ошибки входных данных,
границы диапазона, одиночный канал, сохранение узких пиков, логарифмические
разрывы и экспорт. Проверка EXE в Windows проверяет его запуск без внешнего
Python; совместимость с конкретным компьютером зависит также от его системы.

## Структура и удаление

Все исходники программы и архив находятся в `gamma-spectrum-viewer`.
Сборочный workflow — `.github/workflows/gamma-spectrum-portable.yml`.
Чтобы убрать проект из текущей версии репозитория, удалите эту папку и workflow
и сохраните изменение коммитом. Предыдущие версии остаются в истории Git.
