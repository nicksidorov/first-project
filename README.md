# XeMat

Оконное Python-приложение для совместной обработки SAMPLE и предшествующего
GASBK. Первая версия принимает **подготовленные физические матрицы**; их
построение из времён измерений и калибровок остаётся отдельным следующим этапом.
Вычисления основаны на предоставленной автором статье `XeMat_RU_MASTER_BAYES_V59.tex`.

Сохранены PyQt5, оформление старого интерфейса, IMS-парсер и модуль констант.
Старый проект помещён в `legacy/` для сравнения и не вызывается новым ядром.

## Запуск

Python 3.10 или новее, Windows/Linux/macOS:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
python -m pip install -e ".[test]"
python project.py
```

Выберите файл модели NPZ. Можно обработать его готовые `x,b` или дополнительно
выбрать все три IMS-файла SAMPLE/GASBK/DETBK. При выборе спектров наблюдения
и фиксированный фон берутся из них, а матрицы остаются из NPZ.
Четыре метода доступны в списке окна.

Для демонстрации с синтетическими, **не калибровочными** данными:

```bash
python -m examples.make_demo
python -m xemat.cli examples/demo_model.npz --method wls --output demo_results.json
python -m pytest
```

Допустимые методы CLI: `wls`, `nnls`, `poisson`, `poisson_nonnegative`.
Безголовый запуск окна для технической проверки: `QT_QPA_PLATFORM=offscreen`.
Результаты проверок и ограничения перечислены в [docs/validation.md](docs/validation.md).

## Подготовленные данные

[Формат NPZ и математика](docs/mathematics.md) описывает координаты, веса,
формулы и соответствие переменных статье. Пример формирования файла находится
в [examples/make_demo.py](examples/make_demo.py).

Минимальные поля: `M`, `x`, `b`, целочисленный `n_sample_parameters`, строка
`coordinates`. Вместо `M` можно передать `R_c,R_g1,R_g2,F`.
Для ограничения физических параметров при `coordinates='beta_gamma'` нужна
`T_c`. Для активностей в детекторе нужна `H`; для MDC — физические координаты
и явный список `mdc_component_indices` (индексы ксенона с нуля).

## Структура

- `xemat/model.py`: модель, совместная матрица и координатные преобразования.
- `xemat/solvers.py`: четыре метода, численная диагностика и свободные ковариации.
- `xemat/activities.py`, `xemat/detection.py`: активности, неопределённости, MDC.
- `ims_parser.py`, `constants.py`: сохранённые парсер и константы.
- `process_measurement.py`: связь спектров, подготовленной модели и расчётов.
- `project.py`, `results_saver.py`: окно и отчёт результатов.

Для реального измерения требуется проверенная калибровочная модель и исходные
спектры. В старом архиве есть текстовый отчёт, но нет соответствующих исходных
файлов, поэтому он не является воспроизводимым контрольным примером нового ядра.
MDC использует нормальное приближение статьи; подтверждение частот ошибок на
низких отсчётах требует отдельного исследования Монте-Карло.
