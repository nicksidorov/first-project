# XeMat: только новые эффективности детектора 221

**[Открыть весь отчёт в PDF](report_ru.pdf)** · [Прочитать на GitHub](report_ru.md)

**[Скачать выжимку, графики и таблицу одним архивом](XeMat_new_efficiencies_brief.zip)**

Внутри архива откройте `report_ru.pdf` или `report_ru.html` двойным щелчком. HTML содержит все изображения внутри одного файла и работает без интернета. Для чтения Python не нужен.

Отчёт последовательно показывает:

1. Ложные обнаружения по нашему исходному правилу `Â > Lc` и подробное объяснение точек и полос на рисунке.
2. Выбор множителей `c` на отдельной серии пустых проб.
3. Независимую проверку правила `Â > c·Lc`.
4. Формульные пределы, численные MDC, кривые мощности и интервалы неопределённости.
5. Гистограммы MDC, рассчитанного по каждой реализации наблюдений: при A = 0 и при A = Ld95, отдельно для двух методов и двух майских комплектов.

В каждом графике проверки уровня 5% теперь одна точка на изотоп. Два метода и два майских комплекта разнесены по отдельным панелям; исходное и откалиброванное правила находятся на разных рисунках.

Использованы только фиксированные эффективности SAMPLE/GASBK: Xe135 — 0,241169; Xe133 — 0,367784; Xe131m — 0,233937; Xe133m — 0,233937. Они указаны без branching. Основные результаты Lc/Ld основаны на ранее проверенных 156 000 реализациях. Для гистограмм повторно использованы 20 000 независимых пустых проб из этого исследования и рассчитаны 48 000 новых сигнальных проб. Получено 208 000 оценок MDC без ошибок; пороги и прежние значения Ld95 не перенастраивались.

В гистограммах показан **обычный итерационный MDC из наблюдений**, с α = β = 0,05, без множителя c. Активность A = Ld95 взята из итоговой таблицы после подстройки порога, отдельно для каждой комбинации условий, изотопа и метода. Это фиксированное условие генерации. Центральные 95% значений на гистограмме описывают разброс оценки MDC между пробами и не являются доверительным интервалом истинного Ld95. Учитываются все успешные реализации, независимо от обнаружения.

`brief_data.json` содержит основные результаты с указанными эффективностями; `histogram_summary.json` — статистику дополнения, `histogram_values.npz` — все значения MDC в мБк/м³. Контрольные суммы источников сохранены для прослеживаемости. `sha256.json` проверяет содержимое этого архива. Полные наблюдения и подгонки новой серии находятся в [отдельном архиве исследования](https://github.com/nicksidorov/first-project/tree/xemat-may-ld-graphs/results/may-clean-mdc-eff221-20261022/mdc-histograms). Прежние отчёты и архивы сохранены отдельно и не изменялись.

Независимая проверка (`histogram_verification.json`) воспроизвела все 68 000 векторов отсчётов, сверила 352 контрольные подгонки, 416 независимых решений уравнения MDC и все сводные статистики. Максимальное относительное расхождение для MDC — 1,21·10⁻⁹. Недоступная ковариация свободного ММП в 73 нулевых и 72 сигнальных подгонках не мешала отдельному вычислению MDC по положительному пилоту; эти реализации сохранены.

```bash
python -m pip install -r requirements.txt
python build_brief.py
python render_pdf.py
```

Эти команды строят документы и рисунки; подгонки спектров не запускаются. PDF использует встроенный шрифт с поддержкой кириллицы.
