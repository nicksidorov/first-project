# Xe133m: разброс выдаваемого MDC на двух майских комплектах

В этом эксперименте исследуется случайная оценка MDC, которую выдаёт XeMat по существующей процедуре Lc. Сравниваются МНК и ММП, по 10 000 новых реализаций в каждой из четырёх серий. Приложение не менялось.

## Что означает диапазон на графиках

Диапазон 2,5–97,5% описывает, какие MDC получаются в 95% повторных измерений. Он **не является** доверительным интервалом среднего MDC или истинного Ld. Прежний Ld95 по кривой мощности сам оценён с погрешностью; она приведена отдельно в отчёте.

## Содержимое архива и воспроизводимость

`manifest.json` содержит модели, зафиксированные генерирующие смеси, параметры, версии NumPy/SciPy и SHA256 математического ядра. `trials_compact.npz` содержит все 40 000 исходных пуассоновских векторов и результаты Lc/MDC двух методов. Единицы внутри NPZ — Бк/м³; таблицы и графики используют мБк/м³. Схема данных — `trials_compact_schema.json`.

Прежняя сводка мощности сохранена как `previous_power_summary.json`. Технические 400 реализаций не входят в результаты. Проверки — `validation_review.json` и `verification.json`. Полные промежуточные векторы параметров остаются в рабочей папке исследования; компактный архив сохраняет исходные отсчёты, целевые оценки, пороги и данные, необходимые для повторения расчёта.

Расчёт использует неизменённое ядро XeMat из коммита `3faf592c33f1dfd89ad3fcfee6f41d2893a1748a`. В окружении этого проекта нужно задать `XEMAT_REPO` равным пути к его папке. Скрипт `run_study.py run` использует приложенный manifest и заново создаёт все серии; `verify_results.py` проверяет их; `summarize.py` строит таблицы и графики. Команда `prepare` предназначена только для исходной среды с материалами первого исследования и для воспроизведения из готового архива не нужна.

Пакеты: NumPy, SciPy, Matplotlib. Калибровки фиксированы, систематические неопределённости не моделируются. Исследование относится к двум конкретным генерирующим смесям.
