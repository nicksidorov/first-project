# Номинальный MDC после калибровки Lc к 5%

Эксперимент для чистой пробы и отсутствующей газовой памяти с прежним детекторным фоном 221. Времена, объёмы и калибровки взяты из майских комплектов 22 и 26 мая. При обработке сохраняются все 17 параметров полной совместной модели SAMPLE/GASBK/DETBK.

## Что исследуется

Исходное обнаружение `A_hat > Lc` заменено на `A_hat > c * Lc`. Множитель `c` определяется отдельно для изотопа, метода и комплекта по обучающей нулевой серии. Затем он фиксируется и проверяется на независимой серии пустых проб. Целевые 5% относятся к проверке одного изотопа, а не к вероятности хотя бы одного ложного обнаружения среди всех четырёх. Сам `Lc` по-прежнему пересчитывается для каждой реализации стандартной процедурой XeMat.

После калибровки оценивается активность `Ld95`, при которой достигается около 95% обнаружений. Для мощности повторно используются сохранённые сигнальные реализации, независимые от обучающей и проверочной нулевых серий. Поисковые точки прежнего эксперимента не входят в формальную оценку Ld. Необходимые дополнительные точки мощности описаны в протоколе.

В отчёте различаются формульный номинальный MDC, Ld95 исходного правила и Ld95 после калибровки. Условные интервалы оценивают Ld95 при уже фиксированном множителе `c_hat`. Интервалы с учётом неопределённости калибровки, если доступны, оценивают Ld95 при идеальном множителе `c0` — истинном 95-м квантиле нулевой статистики. Это интервалы оценки предела обнаружения, а не распределения индивидуальных оценок активности. Частоты 5% и 95% оцениваются с погрешностью Монте-Карло, а не гарантируются ровно для конечного числа наблюдений. По проверочной серии множитель повторно не настраивается.

## Данные и воспроизведение

`manifest.json` сохраняет модели, условия измерения и происхождение исходных данных. `summary.json` содержит все численные результаты, включая калибровку, независимую проверку и точки мощности. Единицы таблиц и графиков — **мБк/м³**; вероятности в JSON — доли, а не проценты.

Команда `python report.py` восстанавливает таблицы и графики из готовых `summary.json` и `manifest.json`; повторные подгонки для неё не нужны. Требуются NumPy и Matplotlib.

Команда `python analyze.py` заново вычисляет сводку из сохранённых результатов: зафиксированной калибровки, её bootstrap и независимых проверочных и сигнальных серий. Архив содержит все новые серии в папке `points` без изменений. Сигнальные серии прежнего исследования вместе с дополнительными точками сохранены в `portable_signal.npz`; этот файл и его индекс используются, если соседняя папка прежнего исследования отсутствует. Для анализа дополнительно нужна SciPy. После анализа выполните `python report.py`.

В переносимом сигнальном файле сохранены все 21 отсчёт каждой реализации и оценки целевого изотопа для обоих методов: свободная оценка, неотрицательная оценка, Lc и отношение оценки к Lc. Единицы оценок в этом NPZ — **Бк/м³**. Индекс сохраняет порядок блоков, исходные метаданные, seed и SHA-256 исходных файлов. `prior_manifest.json` и `prior_summary.json` — точные копии документов прежнего исследования. Контрольные суммы содержимого архива перечислены в `sha256.json`.

Команда `python verify.py --portable --output /tmp/verification.json` независимо проверяет распакованные данные, включая новые исходные серии, калибровку и переносимые сигнальные блоки. Она не меняет файлы архивного отчёта. Для проверки повторными подгонками нужен проект XeMat; путь задаётся переменной `XEMAT_REPO`. Команда `python package.py` собирает архив только после успешной независимой проверки и завершения сигнальной сетки.

Для полного повторения подгонок нужен проект XeMat указанной в `manifest.json` версии. Переменная окружения `XEMAT_REPO` задаёт путь к его папке. `XEMAT_PREVIOUS_STUDY` при необходимости задаёт путь к прежнему исследованию с полными сигнальными реализациями; по умолчанию ищется соседняя папка `may-clean-background-mdc`.

Полный эксперимент повторяется **в отдельной рабочей копии**, содержащей скрипты, `manifest.json` и планы, но ещё не содержащей файлов замороженной калибровки:

```bash
python study.py --plan calibration_plan.json
python calibration.py --freeze
python study.py --plan validation_plan.json
```

`calibration.py --freeze` использует только обучающую серию и создаёт `calibration.json`, `calibration_bootstrap.npz` и `cutoff.json`. Уже зафиксированную калибровку команда не перезаписывает. Проверочные результаты не используются для её настройки.

После фиксации коэффициентов `python analyze.py --preview` проверяет покрытие сигнальной сеткой, не читая проверочную нулевую серию. Если требуется расширение, используются отдельно сохранённые планы новых независимых точек; их запускают той же командой `python study.py --plan ИМЯ_ПЛАНА.json`. Окончательные `python analyze.py` и `python report.py` выполняются после завершения независимой проверки и всех запланированных сигнальных точек. Планы, seed и ограничения анализа описаны в протоколе.

Используется неизменённое математическое ядро XeMat. Детекторный фон оценивается заново в каждой реализации. Систематические ошибки не включены. Результат относится к указанному чистому фону и условиям измерения; перенос на произвольные смеси требует отдельной проверки.
