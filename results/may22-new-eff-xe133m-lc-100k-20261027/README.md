# XeMat: майский опыт с новыми эффективностями 221

[Открыть отчёт](report.md) · [Таблица CSV](summary.csv) · [Рисунок PDF](false_detections.pdf)

Проверка ложных обнаружений свежего Xe133m: 100 000 общих для МНК и
пуассоновского ММП реализаций SAMPLE/GASBK/DETBK. Обнулена только свежая
Xe133m; остальные компоненты сохранены из опорной совместной подгонки
реальных майских спектров с новыми эффективностями.

Сначала откройте `report.md`: там приведены сценарий, калибровки, частоты,
точные 95%-е интервалы и диагностика. `replicates_schema.md` описывает все
поля полного массива `replicates.npz`. В архиве сохранены все 100 000 строк,
исходные измерения и снимок математического ядра. MDC и LD не рассчитывались.

Для работы со скриптами: Python 3.12, зависимости из `requirements.txt`.
Из каталога этого отчёта:

```bash
python -m pip install -r requirements.txt
python plot_false_detections.py
```

Последняя команда меняет только рисунок, используя `summary.csv`.
Для пересборки таблиц и отчёта из полных сохранённых результатов:

```bash
python analyze.py --from-replicates
```

Независимая проверка сохранённых результатов, без новых подгонок:

```bash
python verify_study.py --from-replicates
```

`scenario.json` содержит seed и условия генерации; `scenario_arrays.npz` —
матрицы и истинное среднее. Для намеренного полного повторения Монте-Карло:
`python study.py --workers 4`, затем `python analyze.py`. Для просмотра
результатов эти длительные команды не нужны. Сценарий уже зафиксирован:
`prepare_scenario.py` не перезаписывает имеющиеся файлы.

`checksums.json` содержит контрольные суммы файлов архива.
`figure.tex` — пример включения рисунка в статью; основная статья не изменялась.
