# XeMat: чистая проба, 22 мая, 100 000 проверочных реализаций

**[Открыть отчёт PDF](report_ru.pdf)** · [Прочитать на GitHub](report_ru.md)

**[Скачать отчёт, графики и таблицы одним ZIP](XeMat_May22_clean_MDC_100k_report.zip)**

В архиве откройте `report_ru.pdf` или `report_ru.html` двойным щелчком.
HTML содержит рисунки внутри одного файла и работает без интернета.
Для чтения Python не нужен.

Исследован один комплект условий — 22 мая, детектор 221, только новые
эффективности SAMPLE/GASBK. В истинной пустой пробе нет свежей активности
и газовой памяти; остаётся детекторный фон. Все 21 отсчёт SAMPLE/GASBK/DETBK
разыгрываются по Пуассону, все 17 параметров оцениваются заново.

Что есть в отчёте:

1. Исходное правило `Â > Lc`, его ложноположительные частоты и подробное
   объяснение графика проверки уровня 5%.
2. Подстройка множителя `c` на 100 000 отдельных пустых пробах и независимая
   проверка `Â > c·Lc` на других 100 000 пробах.
3. Формульные Lc/MDC, численные Ld95 исходного и откалиброванного правила,
   кривые мощности и интервалы Монте-Карло. Каждый сигнальный узел содержит
   20 000 наблюдений.
4. Гистограммы обычного итерационного MDC по наблюдениям при A = 0 и A = Ld95,
   по одному рисунку для МНК и ММП. Множитель c в формулу этих MDC не вводится.
5. Отдельная проверка мощности на новой серии A = Ld95, не использованной
   для определения самого Ld95. По ней пороги и Ld95 не перенастраивались.

Тест Вальда не используется. Систематические ошибки и неопределённость
выбранного истинного фонового среднего не разыгрываются.

`report_data.json` содержит проверенные сводные результаты этой новой серии,
условия и контрольные суммы источников. `histogram_values.npz` содержит все
значения MDC в **мБк/м³**, включая недоступные попытки как NaN, если они есть.
Null-гистограммы используют те же 100 000 проверочных наблюдений, поэтому
их нельзя прибавлять к общему числу сгенерированных векторов второй раз.
В сигнальных гистограммах по 20 000 проб на каждое сочетание метод/изотоп.

Центральные 95% значений гистограммы описывают разброс MDC отдельных проб.
Это не доверительный интервал истинного Ld95. Включены все доступные MDC
независимо от обнаружения. `sha256.json` позволяет проверить содержимое архива.

Для восстановления оформления из готовых результатов:

```text
python -m pip install -r requirements.txt
python build_report.py
python render_pdf.py
python package_report.py
```

Эти команды не генерируют новые наблюдения и не подгоняют спектры. Полный
расчёт и независимая проверка находятся в соседней папке исследования.
`prepare_report_data.py` используется только при сборке из этого полного
исследования; для чтения или восстановления оформления выжимки он не нужен.
